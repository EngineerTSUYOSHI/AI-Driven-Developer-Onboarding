# AI-Driven-Developer-Onboarding

未経験、微経験エンジニア向けのAI駆動開発を経験してもらうまでの簡易カリキュラム。
生成AIを活用し、初学者を最速で実務レベルの「自走状態」へ引き上げるためのモダン開発育成カリキュラムです。
本リポジトリには、カリキュラムの全容と、学習者の自己解決を支援する「AI自動QAエージェント（GitHub Actions × Gemini API）」が実装されています。

## カリキュラムの目的
- ティーチング（教える）コストを最小化し、AIエージェントを用いた自己解決能力を養う。
- ローカルでのコード記述からクラウドへのデプロイまで、実務のフルサイクルを経験させる。
- Git/GitHubを用いたチーム開発の作法と、CI/CDによる自動化の基礎を定着させる。

## 育成フェーズ（4ステップ）

### Phase 1: 環境構築とAIペアプロ体験
- GitHubアカウントの作成とPR（Pull Request）フローの理解
- AI開発エージェント（Antigravity / Cursor等）の導入
- AIとの対話を通じた簡易アプリケーション（じゃんけんゲーム等）の自律的実装

### Phase 2: 開発サイクルの定着とデプロイ
- CRUD操作を含むWebアプリケーション（ToDoアプリ等）の実装
- Google Apps Script（GAS）やCloud Runを用いた、Web上への公開（デプロイ）体験

### Phase 3: 現場のトラブルシューティング実践
- 意図的なコンフリクトの発生と解消手順の習得
- 誤ったマージからのRevert（切り戻し）操作
- ブランチ間のCherry-pickや特定ファイルの取り込み

### Phase 4: 品質の自動化とチーム開発
- プロンプトエンジニアリングによるテストコードの自動生成
- GitHub Actionsを活用したCI/CDパイプラインの構築
- **[本リポジトリの実装]** IssueとGemini APIを連携させた、ドキュメントベースの自動QAボットの構築
